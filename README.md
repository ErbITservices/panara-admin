# 🛍️ Panara Admin

**Panara Admin** is a React-based administrative dashboard developed to manage the Panara platform. This project utilizes modern web development practices to deliver a responsive and user-friendly experience for administrators.

---

## 🌟 Overview

This admin dashboard provides:

- 🔐 **Secure login system** with role-based access.
- 🛒 **Product and Inventory Management** with support for categories and variants.
- 📦 **Order Tracking & Fulfillment** tools.
- 👥 **User Management** including roles and permissions.
- 📊 **Dashboard Analytics** with charts and KPIs.
- ⚙️ **Configurable Settings** for flexible customization.

## 🚀 Features

- ⚛️ **React Framework**: Built using Create React App for streamlined development.
- 🧩 **Component-Based Architecture**: Modular and reusable components for scalability.
- 🎨 **Responsive Design**: Ensures optimal viewing across various devices.
- 🛠️ **State Management**: Efficient state handling for dynamic data.
- 🌐 **Environment Configuration**: Utilizes `.env` files for environment-specific settings.

| Tech           | Description                          |

## 📦 Installation

1. **Clone the repository:**

```bash
   git clone https://github.com/ErbITservices/panara-admin.git
   cd panara-admin
```

2. **Install dependencies:**

```bash
   npm install
```
3. **Start the development server:**

```bash
   npm start
```
4. **Open your browser and visit:**

```bash
   http://localhost:3000/
```
